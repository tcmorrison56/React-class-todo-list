# React App Todo List

The name of the app will be TiMo ToDo, and it is a Todo list app that I am building to learn how to build web applications with the React library.

## Installation

1. Clone the repository onto your local machine using the command line command: `git clone <repository URL>`
2. Run the command `npm install` to install all the dependencies.

## Run Dev Environment

Once the dependencies are installed use the command `npm run dev` to start the development server and see changes live.
